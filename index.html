Ph.D. · AI research & tools · vintage computing · photography

Gian Luca Bailo

After a Ph.D. in electronic and computer engineering and research at the Istituto Italiano di Tecnologia, I now work in applied AI R&D in Genoa. I run large language models on recycled hardware, study when a fast decision model should stop and think, restore retro computers and still write code for the Commodore 64, these days with AI agents next to me. Away from the keyboard, I photograph the Ligurian coast in natural light.

01 Projects

strata-cluster

C++

One 125B mixture-of-experts model split across two home PCs over plain gigabit Ethernet. An unofficial, experimental fork of the Strata inference engine.

distributed inference · MoE · Linux

System Switch

Python

When should a fast decision model stop and think? Code and data of the paper: a learned actor plays Doom and hands control to a reasoning vision-language model only when a gate opens.

decision models · VLM · ViZDoom

C64AIToolChain

C · 6510 asm

AI agents that write, debug and even playtest Commodore 64 assembly games, through a feedback loop with the VICE emulator and Python visual checks.

agents · Commodore 64 · ★ 29

doomgemma

Python

The Laya System One decision model against Gemma 4 E2B and Gemma 3 270M fine-tuned with LoRA on the same data, in FreeDoom: accuracy, calibration, latency and real games.

LoRA · Gemma · adapters on HF

In Search of an Author

Python

A multi-agent system for writing a book together, inspired by Pirandello: the characters are autonomous agents with their own memories and voices.

multi-agent · RAG · literature

progressive-cognitive

Python

Can a small LLM move from brute-force memorization to intuition and tool delegation? A proof of concept on Qwen2.5 with LoRA and structured pruning.

LoRA · pruning · 10 adapters on HF
